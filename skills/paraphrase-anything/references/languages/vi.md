# Vietnamese notes

- **Xưng hô (pronouns):** keep the original's pronoun pair (tôi/bạn, em/anh, chúng tôi/quý khách).
  Change it only if the requested tone requires (formal → "quý vị", casual → "mình/bạn").
- **Register:** formal writing prefers Sino-Vietnamese vocabulary (thực hiện, triển khai);
  casual prefers native words (làm, bắt đầu). Do not mix registers within one text.
- **Number format:** Vietnamese uses `.` for thousands and `,` for decimals (`1.000,5`).
  Keep the original format; `pe check` compares by value using this convention.
- **Hedges:** "có thể", "có lẽ", "dường như", "khoảng", "gần như" must survive with the same
  strength. Do not turn "có thể tăng" into "sẽ tăng".
- **Negation:** "không", "chưa", "chẳng", "đừng", "không hề". "chưa" (not yet) ≠ "không" (not);
  keep the distinction.
- **Clichés to avoid:** "trong bối cảnh", "đóng vai trò quan trọng", "trong thời đại ngày nay",
  "có thể nói rằng", overusing "không chỉ… mà còn". Prefer concrete wording.
- **Diacritics:** always write full diacritics; never output unaccented Vietnamese.
- **Proper nouns:** multi-syllable names keep each syllable capitalised (Hà Nội, Nguyễn Văn A).
