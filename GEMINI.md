# paraphrase-anything

Use this skill whenever the user asks to paraphrase, rewrite, reword, or produce variants of
text or a `.txt` / `.md` file. The tooling runs with
`python skills/paraphrase-anything/scripts/pe.py <command>` relative to this extension's folder
(use `python3` if `python` is not Python 3).
